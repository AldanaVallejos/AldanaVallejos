## 🚀 Proyectos personales

### ✈️ Mano Viajera

Proyecto personal orientado a conectar personas que necesitan ayuda durante sus viajes con personas dispuestas a colaborar.

La idea nace de buscar una solución tecnológica para una necesidad cotidiana, priorizando una experiencia simple y humana.

**Conceptos principales:**

* Solicitudes y ofrecimientos de ayuda
* Perfiles de usuarios
* Mensajería
* Notificaciones
* Sistema de valoraciones
* Autenticación
* Validación de identidad
* Diseño orientado a una futura evolución del producto

> Un proyecto pensado no solamente como portfolio, sino como una oportunidad para explorar cómo transformar una idea en un producto de software.

---

### 🏠 Casas Hoy — Solidez Total

Aplicación orientada a la gestión y comercialización de viviendas prefabricadas.

Proyecto desarrollado con foco en una arquitectura organizada y escalable, aplicando conceptos de **Clean Architecture y TDD**.

**Tecnologías y conceptos:**

`TypeScript` · `React` · `Node.js` · `Clean Architecture` · `TDD`

---

### 🐾 Huellitas

MVP para la gestión de servicios de veterinaria y guardería canina.

El proyecto contempla funcionalidades para la gestión de mascotas, clientes y servicios, buscando resolver necesidades concretas de un negocio real.

**Objetivo:** desarrollar una solución simple, útil y preparada para futuras ampliaciones.
